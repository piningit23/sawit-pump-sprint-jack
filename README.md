A launch sniper for make.fun's Pump.fun Replay Sprint (paper bot, real ranking). It buys only fresh pump.fun launches that look organic — a modest creator buy, few distinct early buyers, no creator sell yet, real SOL already flowing in — then gets out fast: partial profit at +10%, full exit at +18%, hard stop at -10%, a trailing stop once up +12%, a 15-slot max hold, and an instant exit if the creator sells while we hold. Pure function of the replay batches: no clock, no randomness, no I/O.

## Run it

```sh
node main.ts
```
